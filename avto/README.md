# Сайт отдела автоперевозок

Внутренний сайт отдела автоперевозок ТОО «Zhebe Logistics»: реестр рейсов с временем каждого этапа,
подсветка нарушений сроков регламента, воронка новых клиентов, дневной отчёт и сводка для руководства.
Excel для 1С выгружается из сайта в прежнем формате.

- Работает на одном офисном компьютере, сотрудники открывают его в браузере по локальной сети.
- Без почты и регистрации: сотрудник выбирает своё имя и вводит PIN.
- Без интернета, без платных сервисов. Все данные — в одном файле `data\avto.db`.

## Установка (один раз)

Выберите компьютер, который всегда включён в рабочее время. Это будет «сервер».

**Вариант 1 — через Python.**
1. Установите Python 3.11 или новее с https://www.python.org/downloads/. В установщике отметьте **Add Python to PATH**.
2. Скопируйте папку `avto` на этот компьютер, например в `C:\avto`.
3. Дважды щёлкните `start.bat`. При первом запуске он сам поставит библиотеки (нужен интернет, 1–2 минуты).

**Вариант 2 — один файл `avto.exe`, без Python.**
1. На любом компьютере с Python запустите `build_exe.bat`. Появится файл `dist\avto.exe`.
2. Положите `avto.exe` и `start.bat` в папку `C:\avto` на компьютере-сервере. Запускайте `start.bat`.

## Запуск и адрес сайта

Запустите `start.bat`. Откроется чёрное окно с адресом вида `http://192.168.1.25:8000`.
**Раздайте этот адрес сотрудникам** — они открывают его в Chrome или Edge (с телефона тоже, если он в офисном Wi-Fi).
Тот же адрес показан внизу страницы входа.

Пока окно открыто, сайт работает. Закрыли окно или выключили компьютер — сайт недоступен.

Если браузер на другом компьютере не открывает сайт: при первом запуске Windows спросит про брандмауэр —
нажмите **Разрешить доступ** (частная сеть). Если вопрос не появился: Панель управления → Брандмауэр Защитника
Windows → Разрешение взаимодействия с приложением → добавьте Python (или `avto.exe`).

Чтобы адрес не менялся, попросите того, кто настраивал роутер, закрепить за этим компьютером постоянный IP.

Порт можно сменить: в `start.bat` перед строкой запуска добавьте `set AVTO_PORT=8080`.

### Автозапуск при включении компьютера

1. Нажмите `Win + R`, введите `shell:startup`, нажмите Enter — откроется папка «Автозагрузка».
2. Щёлкните правой кнопкой по `start.bat` → **Создать ярлык**, перенесите ярлык в эту папку.

Теперь сайт запускается сам, когда пользователь входит в Windows.

## Первый вход

1. Откройте сайт. Он предложит задать **PIN администратора** (4–6 цифр).
2. В разделе **Админ → Сотрудники** задайте PIN каждому сотруднику. Уже созданы: Жексебаев М., Меден Д.
   (менеджеры), Тулебаев М. Б. (руководитель отдела). Добавьте руководство (финансовый, коммерческий,
   операционный директор) с ролью «Руководство». **Имя должно совпадать с колонкой «Сотрудник» в реестре.**
3. **Админ → Импорт реестра**: загрузите октябрьский реестр (и другие месяцы). Сначала «Проверить файл» —
   сайт покажет, сколько строк новых, обновлённых и пропущенных, — затем «Загрузить в базу».
4. **Админ → Настройки**: проверьте план, минимальную маржу, нормы и праздничные дни.

## Роли

| Роль | Видит | Может |
| --- | --- | --- |
| Менеджер | Все рейсы отдела, свои лиды и отчёты, сводку по себе | Создавать и менять рейсы и лиды, сдавать свой отчёт, выгружать Excel для 1С |
| Руководитель отдела | Всё | То же плюс переназначать рейсы и лиды, удалять записи, править любые отчёты |
| Руководство | Сводку, реестр, воронку, отчёты | Только просмотр и выгрузка Excel |
| Администратор | Всё | Всё плюс настройки, сотрудники, PIN, справочники, импорт, восстановление удалённого |

Права проверяет сервер при каждом запросе, а не только интерфейс.

## Выгрузка для 1С

**Реестр → «Выгрузить для 1С»** — файл `Реестр авто <Месяц Год>.xlsx`. В него попадают рейсы выбранного месяца
на этапах «Загружен» и дальше, по дате отправки, № с 1. Если выбран сотрудник — только его рейсы.
Колонки, заголовки (с пробелами в конце, пустой колонкой U), шрифт и форматы — как в нынешнем реестре.
«Разница» записана формулой `=SUM(Hn-On)` вместе с готовым значением.

Если загрузка 1С ругается на заголовок, точные строки заголовков лежат в одном месте:
`app/excel_io.py`, список `EXPORT_HEADERS`.

## Резервные копии

Раз в сутки база копируется в папку `backup\` (рядом со `start.bat`) с датой в имени: `avto_2026-11-03.db`.
Хранятся 30 последних копий. Папку можно поменять в **Админ → Настройки** — например, на сетевую
`\\SERVER\share\avto-backup`. Копию вручную: **Админ → Резервные копии → Сделать копию сейчас**.

Дополнительно **Админ → «Выгрузить все данные»** сохраняет все таблицы в один `.xlsx`.

### Восстановление

1. Закройте окно сайта (сайт остановится).
2. Откройте папку `data`, переименуйте `avto.db` в `avto_старый.db` (на всякий случай).
   Если рядом лежат `avto.db-wal` и `avto.db-shm`, переименуйте и их.
3. Скопируйте нужный файл из `backup`, например `avto_2026-11-02.db`, в папку `data` и переименуйте его в `avto.db`.
4. Запустите `start.bat`. Сайт откроется с данными на дату копии.

### Перенос на другой компьютер

Скопируйте всю папку `avto` (вместе с `data`) на новый компьютер и запустите `start.bat`.

## Как устроено (для программиста)

- `app/logic.py` — все расчёты (этапы, рабочее время, метки сроков, сводка). Без базы данных, покрыт тестами.
- `app/services.py` — операции с данными, права, журнал изменений, конфликт версий.
- `app/excel_io.py`, `app/importer.py` — выгрузка для 1С, импорт старых реестров, выгрузка всех данных.
- `app/main.py` — веб-сервер FastAPI; `app/static/` — страница (чистый JavaScript, без CDN).
- `app/backup.py` — ежедневные копии. `app/db.py` — схема SQLite.
- Время ставит сервер, часовой пояс Алматы (UTC+5). PIN хранится как PBKDF2-HMAC-SHA256 с солью.
  Сессия — 12 часов, 5 неверных PIN подряд блокируют вход на 15 минут.
- Удаление мягкое (признак `deleted`), восстанавливает администратор в **Админ → Удалённые**.

Тесты:

```bash
pip install -r requirements-dev.txt
python -m pytest
```

`tests/sample_registry.py` создаёт выдуманный реестр с теми же контрольными цифрами, что октябрьский
(26 рейсов, выручка 12 344 000 ₸, маржа 2 493 000 ₸, Coca Cola — 44% маржи). Тесты проверяют импорт,
выгрузку ячейка в ячейку, сводку, сроки регламента и права.

## Приёмка (п. 9.5 ТЗ)

Автотесты проверяют на тестовом реестре: импорт (26 рейсов, пустая строка пропущена, повторный импорт без
дублей), совпадение выгрузки с исходником, цифры сводки, метки «Ставка не отправлена» (в т.ч. заявка в 17:30 →
10:30), «Нет связи 13 ч», «Не закрыт 6 рабочих дней», запрет менеджеру на настройки и чужой отчёт прямым запросом,
резервную копию. **Вручную остаётся**: импорт настоящего октябрьского файла, сравнение выгрузки с ним и
загрузка выгруженного файла в тестовую базу 1С.
