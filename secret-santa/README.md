# Тайный Санта (Ocean Love, зимний голубой дизайн)

Отдельный сайт для жеребьёвки подарков для любой компании: друзей, семьи, коллег. С сайтом `santa/` (Zhebe) и бюджетом не связан:
свой адрес, своё хранилище, свои игры.

## Как выложить (один раз)
1. https://app.netlify.com → **Add new project → Import an existing project → GitHub** → репозиторий `Zhibek`.
2. **Base directory:** `secret-santa` (остальное заполнится из `secret-santa/netlify.toml`).
3. **Deploy**. Имя сайта меняется в **Site configuration → Change site name**.
4. Если внизу сайта написано **Private**, нажмите **Make public**, иначе коллеги его не откроют.

## Что умеет
- Организатор создаёт игру, получает код и приглашение для чата на двух языках.
- Участники регистрируются с именем, пожеланием и PIN, после жеребьёвки открывают коробку с подопечным.
- Организатор видит пары (по паролю) и может задать новый PIN тому, кто его забыл.
- Казахский и русский язык (переключатель ҚАЗ / РУС), название и комментарий игры на обоих языках.

## Файлы
- `public/index.html`: страница, `public/santa.jpg`: картинка, `public/ocean-love-logo.png`: логотип.
- `netlify/functions/santa.mjs`: сервер (`/santa-api/*`, хранилище Netlify Blobs).
