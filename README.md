# Личный бюджет

Сайт для планирования личного бюджета в тенге: журнал операций, лимит на сегодня,
категории с лимитами, обязательные платежи, цели накоплений и итоги года.

- Вход по **логину и паролю**, почта не нужна.
- У каждого свой закрытый бюджет: никто не видит чужие записи, даже владелец сайта.
- Три оформления: «Нежная» (пастель), «Холодная», «Изумрудная».
- Удобно с телефона: нижнее меню, добавление записи в два касания, свайп по месяцам.
  Можно добавить на главный экран как приложение.

Всё работает на Netlify (бесплатно): страницы, сервер (Netlify Functions) и хранилище (Netlify Blobs).
Сторонние сервисы не нужны.

## Как выложить
1. Зайдите на https://app.netlify.com (можно войти через GitHub).
2. **Add new site → Import an existing project → GitHub** → выберите этот репозиторий.
3. Настройки сборки уже лежат в `netlify.toml` — просто нажмите **Deploy**.
4. Через минуту сайт будет по адресу вида `https://имя.netlify.app`.
   Имя меняется в **Site configuration → Change site name**.

Каждое изменение в репозитории выкладывается на сайт автоматически.

## Первый вход
Откройте сайт: пока на нём никого нет, он предложит создать **аккаунт владельца**.
Владелец в «Настройках → Аккаунты на сайте» создаёт логины и пароли другим людям,
меняет им пароль, если забыли, и может удалить аккаунт.

## Необязательные настройки (Netlify → Site configuration → Environment variables)
- `ALLOW_SIGNUP` = `true` — люди смогут сами создавать аккаунт на сайте (по умолчанию выключено).
- `AUTH_SECRET` — свой секрет для подписи входа. Если не задан, сайт создаёт его сам.

## Как устроено
- `public/` — сам сайт (одна страница `index.html`).
- `netlify/functions/api.mjs` — сервер: вход, аккаунты, сохранение данных.
- Пароли хранятся только в виде хеша (scrypt). После 10 неверных попыток вход блокируется на 15 минут.
- Смена или сброс пароля завершает старые сеансы на всех устройствах.
- Если сайт открыт без сервера (например, файлом с компьютера), записи сохраняются только в браузере.

# Английский каждый день (`/english/`)

Второй сайт в этом же репозитории: простой тренажёр английского. Открывается по адресу
`https://имя.netlify.app/english/`.

**Вход и прогресс на всех устройствах**
- Аккаунты **те же, что у бюджета**: тот же логин и пароль. Если вы уже вошли в бюджет в этом браузере,
  английский узнает вас сам. Новые аккаунты создаёт владелец в бюджете («Настройки → Аккаунты на сайте»).
  Если включено `ALLOW_SIGNUP`, люди могут создать аккаунт сами прямо на странице входа.
- Прогресс хранится на сервере (`/api/english`) и сливается между устройствами без потерь:
  XP за день складывается, уроки, слова, достижения и серия объединяются.
- Без интернета всё работает, а сохранится, когда связь вернётся (значок ☁️/⚠️ рядом с названием).
- Можно «Продолжить без входа»: тогда прогресс хранится только в этом браузере.
  При входе он перенесётся в аккаунт.
- При выходе прогресс стирается из браузера (на сервере остаётся), так что общий компьютер безопасен.
- Ещё есть «Сохранить / Загрузить» прогресс в файл.

**Как учит**
- 20 тем (от «Знакомства» до «Телефона и интернета»): 200 слов и 80 фраз, по 2 коротких урока (около 5 минут) на тему.
- В уроке: знакомство со словом и озвучка, выбор перевода, «соедини пары», аудирование,
  сборка фразы из слов, написание слова. Ошибки возвращаются в конце урока.
- В каждой теме короткое правило грамматики: to be, Present Simple и Continuous, Past Simple, Present Perfect,
  will / going to, сравнение, вежливые просьбы, фразовые глаголы и другие.
- Интервальное повторение: изученные слова возвращаются через 1, 2, 4, 7, 15 и 30 дней.

**Как держит мотивацию**
- Цель дня (15–80 XP) с кольцом прогресса и **серия дней 🔥**. За каждые 7 дней подряд даётся
  **заморозка ❄️**, она спасает серию при пропуске.
- Уровни, 14 достижений, звёзды за уроки, конфетти, цитата и слово дня.
- «Спринт 60 секунд» с рекордом и комбо.
- Неделя в графике и календарь занятий. Сообщения подстраиваются под цель
  («путешествия», «работа», «учёба», «для себя»).

Файлы: `public/english/index.html` (весь сайт), `icon.svg`, `manifest.webmanifest`
(можно добавить на главный экран телефона).
