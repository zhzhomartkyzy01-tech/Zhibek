# Личный бюджет

Сайт для планирования личного бюджета в тенге: журнал операций, лимит на сегодня,
категории с лимитами, обязательные платежи, цели накоплений и итоги года.

- Вход по **логину и паролю**, почта не нужна.
- У каждого свой закрытый бюджет: никто не видит чужие записи, даже владелец сайта.
- Три оформления: «Нежная» (пастель), «Холодная», «Изумрудная».
- Удобно с телефона: нижнее меню, добавление записи в два касания, свайп по месяцам.
  Можно добавить на главный экран как приложение.

Всё работает на Netlify (бесплатно): страницы, сервер (Netlify Functions) и хранилище (Netlify Blobs).
Сторонние сервисы не нужны.

## Как выложить
1. Зайдите на https://app.netlify.com (можно войти через GitHub).
2. **Add new site → Import an existing project → GitHub** → выберите этот репозиторий.
3. Настройки сборки уже лежат в `netlify.toml` — просто нажмите **Deploy**.
4. Через минуту сайт будет по адресу вида `https://имя.netlify.app`.
   Имя меняется в **Site configuration → Change site name**.

Каждое изменение в репозитории выкладывается на сайт автоматически.

## Первый вход
Откройте сайт: пока на нём никого нет, он предложит создать **аккаунт владельца**.
Владелец в «Настройках → Аккаунты на сайте» создаёт логины и пароли другим людям,
меняет им пароль, если забыли, и может удалить аккаунт.

## Необязательные настройки (Netlify → Site configuration → Environment variables)
- `ALLOW_SIGNUP` = `true` — люди смогут сами создавать аккаунт на сайте (по умолчанию выключено).
- `AUTH_SECRET` — свой секрет для подписи входа. Если не задан, сайт создаёт его сам.

## Как устроено
- `public/` — сам сайт (одна страница `index.html`).
- `netlify/functions/api.mjs` — сервер: вход, аккаунты, сохранение данных.
- Пароли хранятся только в виде хеша (scrypt). После 10 неверных попыток вход блокируется на 15 минут.
- Смена или сброс пароля завершает старые сеансы на всех устройствах.
- Если сайт открыт без сервера (например, файлом с компьютера), записи сохраняются только в браузере.
