# Тайный Санта

Отдельный сайт для жеребьёвки подарков в коллективе. С сайтом бюджета никак не связан.

## Как выложить (один раз, ~2 минуты)
1. Зайдите на https://app.netlify.com (вход через GitHub).
2. **Add new site → Import an existing project → GitHub** → выберите репозиторий `Zhibek`.
3. В поле **Base directory** впишите: `santa`
   (остальные поля заполнятся сами из `santa/netlify.toml`).
4. Нажмите **Deploy**. Через минуту сайт будет по адресу вида `https://имя.netlify.app`.
5. Красивое имя: **Site configuration → Change site name**, например `santa-otdel` →
   `https://santa-otdel.netlify.app`.

## Как играть
1. Организатор открывает сайт → «Создать новую игру»: название, бюджет, дата, пароль организатора.
   Сайт выдаёт код игры и готовое приглашение для общего чата.
2. Каждый открывает ссылку, нажимает «Я новенький», пишет имя и пожелание и придумывает PIN (4–8 цифр).
3. Организатор видит только, **кто** зарегистрировался, и нажимает «Провести жеребьёвку».
4. Каждый заходит снова, вводит PIN, открывает коробку и видит, кому дарит, и его пожелание.

## Почему никто не узнает пары, даже организатор
- У каждого участника своя пара ключей. Закрытый ключ зашифрован его PIN.
- При жеребьёвке «кому дарить» шифруется ключом дарителя. Пары не хранятся в открытом виде нигде.
- Жеребьёвка идёт по кругу: никто не дарит сам себе, и нет пар «друг другу».
- После 10 неверных PIN вход блокируется на 15 минут.
- Если кто-то забыл PIN, организатор нажимает «Перезапустить жеребьёвку» и проводит её заново.

## Файлы
- `public/index.html`: страница.
- `netlify/functions/santa.mjs`: сервер (`/santa-api/*`, хранилище Netlify Blobs).
